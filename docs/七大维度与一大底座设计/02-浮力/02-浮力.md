# 02 浮力

种子：浮力块　接口：结构 → 结构
**状态：1.0 不做。**

## 为什么后置

没有介质系统，浮力只能是凭空向上的常数力，等于给方块开一个不做物理的后门。

1.0 的飞行改走推力：推进器向下吹，链是完整的（转速 → 推力 → 加速度 → 高度）。代价是没有静浮，悬停要持续供能。

## 形态（后置）

固定向上力，不可调、不可关，只有结构面。

输入里没有信号是故意的：可调浮力会让信号成为本维度的固有依赖。要可控浮力时另做带信号面的新方块。

## 细化

- 可变浮力块（新方块，接信号）
- 浮石（参数变体，浮力大小不同）
- 浮力方向可旋转（浮力块 + 关节，零新方块）
- 浮力随高度衰减（参数，制造升限）

不做热空气：需要热，会引入第五种面。

## 组合与介质

+ 推进器 = 飞艇；+ 关节 = 可抛弃压舱、配平；+ 信号 = 可控升降。

水中浮力块退居配角：水的密度足够大，底座的质量/体积比本身就能决定浮沉。
