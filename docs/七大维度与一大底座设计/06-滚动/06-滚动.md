# 06 滚动

种子：轮子　接口：旋转 → 无（产生切向力）

## 1.0 形态

转速到切向力，摩擦固定。不转向、不悬挂、不刹车。

## 硬约束：碰撞形状

**方块轮子不会滚，只会翻。**

轮子碰撞体必须是圆柱或胶囊，不能是 AABB。这意味着引擎必须先有"非方块碰撞形状"这个原语，否则滚动维度不成立。

这是七个维度里唯一对引擎形状系统提硬要求的地方。

## 细化

- 摩擦档（参数：冰、沙、石）
- 悬挂（零新方块，轮子 + 弹簧）
- 转向（零新方块，轮子 + 关节）
- 刹车（零新方块，轮子 + 信号）
- 履带（新方块，接地面积大、转向靠差速）
- 明轮（零新方块，轮子 + 水介质）

## 组合与介质

+ 关节 = 可转向；+ 动力 = 车；+ 推进器 = 两栖；+ 结构块 = 下压力（越重抓地越紧）。

水中只有两条路：变明轮，或失效。取决于轮子问介质"这里有没有地面支撑"。
