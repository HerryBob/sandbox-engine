# 05 推力

种子：推进器　接口：旋转 → 无（产生力）

## 1.0 形态

转速到力，固定朝向，线性。不反向、不转向。

## 细化

- 反向（零新方块，负转速）
- 矢量推力（零新方块，推进器 + 关节）
- 多叶 / 大口径（参数变体，效率曲线不同）
- 喷气：**否决**，只接燃料、插不进能量流
- 帆：不归本维度，属于后置的风维度

## 关键：力的作用点

装在结构边缘的推进器产生扭矩（偏航），装在质心正后方只产生平移。

**这是"布局"这一玩法的物理来源**，引擎必须支持"力可以作用在任意点"，否则后期补不上。

## 组合与介质

+ 关节 = 矢量推进；+ 轮子 = 两栖；+ 结构块 = 偏移安装就偏航。

水中同转速推力大幅提升（水密度是空气几百倍），力公式里把介质密度当输入即可，不需要新方块。
