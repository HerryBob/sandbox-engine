# 07 约束

种子：关节　接口：结构 → 结构

## 1.0 形态

单轴旋转，无限角度，无阻尼。两个结构面各接一半。

## 硬约束：必须是真约束

不能做成"子物体变换 = 父物体 × 偏移"。那是运动学假连接：不受力、不传扭矩、撑不起结构。

必须是真的铰链约束，参与求解器计算。这决定了 Jolt 侧的结构选择：**多刚体 + 约束**，不是"单刚体 + 多形状"。

## 为什么它重要

它一成立，"部件"这个概念才出现：机械臂、转向轮、可抛弃压舱、可折叠结构全部依赖它。

## 细化

- 限角（参数）
- 弹簧回正（新行为，扭矩 = 负刚度 × 角度）
- 滑块（新方块，线性约束）
- 球铰（新方块，三轴自由）
- 断裂（新行为，超扭矩阈值断开）
- 阻尼（参数，接介质粘度）

## 组合

关节是"让所有终端可变"的乘法器：+ 推进器 = 矢量推力；+ 轮子 = 转向轮；+ 动力 + 杆 = 机械臂（动力穿过转动的关节）。

## 待决策

1.0 是否要"断裂"。它需要结构完整性系统（应力计算），做就是差异化；不做，关节只管运动不管强度。
