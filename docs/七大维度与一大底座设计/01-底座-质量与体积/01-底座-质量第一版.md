# 01 底座：质量与体积

所有方块共享的两个属性：质量、体积。

- 质量 × 重力 = 向下
- 体积 × 浮力系数 = 向上

两个数相遇，浮沉就闭合。少一个描述不出浮沉，多一个（密度）就冗余。

**密度 = 质量 ÷ 体积，只读派生。** 三个都存会出现两个真相：改质量不改体积时，密度既是旧值又是新商。

**体积是排水体积**，不是几何体积。半砖 0.5，气凝胶几何 1、排水 0.2。默认按形状推导，作者只填例外。

默认值：质量 1.0、体积 1.0——一格满方块是世界基准。

数据形态：selector / priority / overrides 三层，是数据不是代码。

## 细化

- 材质档位（参数）
- 非满方块（要形状系统，体积、质心、惯性都变）
- 可破坏块（要结构完整性）
- 无碰撞但有质量（压舱、装饰挂件）
