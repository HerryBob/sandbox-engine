# 08 信号

种子：操纵台　接口：无 → 旋转 + 信号

## 1.0 形态

座椅 + 一个方向输入 + 一个转速输入，输出旋转与信号。三合一，因为人机界面不可再拆。

## 三层必须分开

| 层 | 内容 | 谁决定 |
|---|---|---|
| 值 | 0–15 或模拟量 | 逻辑层 |
| 网络 | 哪些节点连通 | 载体 |
| 载体 | 相邻面、线、频率 | 玩家搭建 |

**载体只决定拓扑，不决定语义。**

## 三个载体

| 载体 | 空间关系 | 跨结构 | 1.0 |
|---|---|---|---|
| 相邻面 | 同一体内紧贴 | 是 | 做 |
| 线 | 同一体内任意 | **否** | 做 |
| 无线 | 跨物理体 | 是 | 后置 |

**"跨界"是无线独有的。** 结构内的线跟着结构动，跨结构一断就失效，所以两者不是替代关系。

## 线是层，不是方块

占格就会占质量、参与碰撞，载具内部一布线就变重、变丑、改质心。

所以线附着在方块表面：六个面各一个信号节点，相邻方块的表面节点之间可连。邻接是"面对面"而非"格对格"。

原版没有同时满足"不占格 + 任意布线 + 可传输"的手段（红石粉占格且只能铺顶面，绊线只能拉直线），这条空白是 1.0 的第一个延伸点。

## 两个建图器，一个传播器

```
建图器（载体）→ 节点图 → 传播器（语义）→ 每个节点的值
```

线按空间邻接建图、无线按频率匹配建图，输出都是"一组连通节点"。**这是"无线不是新系统、是信号的新载体"的技术含义。**

1.0 即使只有线，也必须现在把"网络"抽出来：传播算法不能长在方块更新里（不能写成"检查六个邻居"），否则加无线要重写。

## 重建不能清零

重建（区块加载、装配、读档）时不能"先清零再传播"，否则对外输出瞬时 0——推进器停一帧、灯闪一下。正确做法是算完所有输入再一次性提交。

参照：Create 红石链接在存档加载时会让接收端短暂脉冲关断一次，原因就是默认关 + 重建时出现瞬时 0。

## 两条语义

- **取最强**：多源取最大值
- **不耗能**：信号只传开关或模拟量，能量约束由旋转的应力承担

不耗能是分层的根基：**信号不携带能量，所以才能跨物理边界。**

## 组合

操纵台 + 推进器 = 可开的飞行器；开关 + 线 + 推进器 = 远程启停；传感器 + 逻辑 = 无人的姿态修正。

## 细化

- 开关（新方块，离散信号源，操纵台的降级形态）
- 传感器（新方块，物理量变信号：高度、速度、姿态）
- 逻辑（新方块，信号变信号：反相、与、或、脉冲、延时）
- 仪表（新方块，信号变可读：转速表、应力表、姿态仪）
- 无线（新载体，后置）

## 待决策

线是否衰减（有衰减则距离成为成本、中继器有理由）；中继器是否进 1.0；频道用数据字段；无线半径固定还是可配。
