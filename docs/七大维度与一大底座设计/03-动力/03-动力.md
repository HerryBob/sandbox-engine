# 03 动力

种子：动力块　接口：无 → 旋转

## 1.0 形态

**无限动力源**：恒定角速度，不烧燃料、不受负载影响、不会过载。转速装配期可设，类似机械动力创造马达。

## 配置不是控制

转速是装配期调好的参数，属于方块属性，不是输入。所以输入面仍为空，信号维度没被吃掉。

真正吃信号的是"能接信号改转速"的新方块，那是细化，不是种子。

## 为什么不带燃料、不带应力

1.0 验证的是"旋转能不能驱动结构"，不是"能源够不够"。燃料管能跑多久、应力管能带多重，都会在物理没跑通时制造假失败——飞不起来时分不清是物理错了还是能源不够。

## 细化

- 可接信号（新方块，本维度进入信号体系）
- 需要燃料（新方块，接口不变）
- 应力上限 / 过载停机（系统属性，非方块）
- 水车 / 风车（新方块，后置）
- 反向（参数）

## 不做

能量条、电池。旋转是唯一能量语言，动力块只产生不储存。
