# 方块设计

本文是 1.0 的功能方块**种子上限**，不是完整清单。全集参照见 `功能方块分析.md`。

原则：**初始方块是各维度的开端，后续是细化每个维度，不是补充新维度。**

## 一、四条判据

1. **不可替代**：拿掉它，某种玩法彻底消失，不是变弱
2. **至少两个有效伙伴**：单独存在无意义
3. **接口能承载未来**：输入输出面容纳该维度所有后续实现，不改自身
4. **最不依赖其他维度**

第 3、4 条最硬。种子定了，接口即冻结。

反例即代价：动力块若一开始就接信号，"信号"维度被吃掉一半；推进器若一开始就能反向，"信号"必须先有正反转语义。**每一个提前给的能力，都会变成后面所有实现都要背的参数。**

## 二、一底座 + 七维度

底座 = 质量与体积，所有方块共享。一个方块 = 底座 + 若干能力。结构块是零能力方块，证明底座存在的最小样本。

| 层 | 名称 | 种子 | 1.0 | 输入面 | 输出面 |
|---|---|---|---|---|---|
| 底座 | 质量与体积 | 结构块 | 做 | 结构 | 结构 |
| 能力 | 浮力 | 浮力块 | **不做** | 结构 | 结构 |
| 能力 | 动力 | 动力块 | 做，无限可调 | 无 | 旋转 |
| 能力 | 传动 | 传动杆 | 做，杆 + 齿轮 | 旋转 | 旋转 |
| 能力 | 推力 | 推进器 | 做 | 旋转 | 无 |
| 能力 | 滚动 | 轮子 | 做 | 旋转 | 无 |
| 能力 | 约束 | 关节 | 做 | 结构 | 结构 |
| 能力 | 信号 | 操纵台 | 做 | 无 | 旋转 + 信号 |
| — | 装配杖 | 手持划范围 | 做 | — | — |

细节见 `七大维度与一大底座设计/`。

四对"源与用"：

- **垂直**（底座 + 浮力）：一个提供质量，一个对抗它
- **能量**（动力 + 传动）：一个产生，一个分配
- **转换**（推进器 + 轮子）：旋转变平移的两条路，一条推空气一条推地面
- **意图**（关节 + 操纵台）：一个决定结构怎么相对动，一个决定人怎么介入

砍任何一个都会塌掉一整块：砍关节就没有"部件"，砍操纵台只能推不能开，砍传动每个执行器都得自带动力源。

## 三、四种接口

| 接口 | 含义 |
|---|---|
| 结构 | 参与同一物理体，贡献质量与碰撞 |
| 旋转 | 传递角速度与扭矩 |
| 信号 | 传递开关或模拟量 |
| 无 | 不接收也不输出 |

只有四种，所以组合有限、可穷举、可理解。浮力块的输入里没有信号是故意的——否则信号会成为本维度的固有依赖。

## 四、两种枝

- **新方块枝**：需要新物理或新参数
- **组合枝**：已有种子的组合，不写代码

组合枝的例子：可转向的轮 = 轮子 + 关节；机械臂 = 关节 + 动力 + 杆；两栖 = 动力分两路；明轮 = 轮子 + 水介质。

**一半的细化会自动长出来，这是种子选对了的直接证据。**

## 五、介质

水作为介质 ≠ 流体系统。水能浮船不需要流动的水，只需一个体素标记 + 一张属性表。

统一一次查询：

```cpp
struct MediumSample
{
    float density;    // 密度
    float viscosity;  // 粘度
    bool  hasGround;  // 是否提供地面支撑
};
```

四个改动共享这一个接口：
- 推进器：力 = 系数 × 转速² × density
- 轮子：hasGround 真走切向力，假走明轮
- 结构块：浮力 = 密度差 × 体积
- 关节：阻尼 += viscosity × 系数

水中浮力块退居配角，因为底座的质量/体积比本身就能决定浮沉。

**分级**：1.0 只有空气 → 1.1 静态水（全浸没可浮沉，不能浮在水面）→ 1.2 自由液面。

水面是唯一技术断层：部分浸没时浮力连续变化，必须从二值改为连续采样。

## 六、实现顺序

按目标体验倒推，不按技术难度：

1. **信号**（传感器、开关）：从"能飘"到"能开"
2. **约束**（限角、弹簧）：从"整体"到"有姿态的机构"
3. **传动**（齿轮、离合）：布局开始有深度
4. **推力与滚动**（矢量、悬挂、摩擦）：手感

前两个决定能不能玩，后两个决定好不好玩。

## 七、明确不做

- 齿轮只做 2:1 与同尺寸反向，任意变速比等应力系统
- 锥齿轮 / 变速箱 / 皮带：1.0 不做
- 配重块：用结构块堆即可
- 风车：依赖风系统
- 绳索 / 对接器：1.0 只做单体
- 浮力：整体后置，等介质

## 八、待决策

1. 动力块是否内置燃料槽（1.0 不进燃料）
2. 轮子碰撞形状必须非 AABB（圆柱或胶囊）
3. 关节是否用真约束求解（决定 Jolt 侧"多刚体 + 约束"）
4. 操纵台是否三合一
5. 结构块是否区分密度档位
