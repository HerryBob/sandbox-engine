# 引擎框架

>2026-10-23

## 源码地图

```
src/
    -main.cpp               #入口: 负责启动引擎
    -business/              #业务线程: 负责引擎的业务层面内容
        -BusinessWorld.hpp      #声明所有业务世界的变量, 函数
        -BusinessWorld.cpp      #实现业务世界的变量, 函数
    -core/                  #核心基础设施: 日志/单向队列/线程控制/时间管理器
        -Log.hpp                #日志文件: 负责输出日志信息
        -SPSCQueue.hpp          #无锁环形队列: 一个在两条线程之间的队列 负责传递事件 两条线程固定一条只读, 一条只写
        -ThreadLoop.hpp         #轻量线程封装: 设计只能出现一个线程, 无法被复制, 控制线程的运行, 生命周期, 适配lambda写法
        -TimeManager.hpp        #时间管理器类: 负责调控物理线程, 业务线程, 全域时间等参数    
    -input/                 #输入线程: 负责玩家输入(真实键盘/鼠标), 归本文件夹独占
        -InputSampler.hpp       #真实输入采样器: 注册GLFW键盘/鼠标回调 + 输入线程消费增量更新相机写PlayerInput
        -InputSampler.cpp       #实现: attach注册回调, sample()采样, 静态回调(keyboard/mouseButton/cursorPos)
    -physics/               #物理线程: 负责引擎的物理层面内容
        -PhysicsWorld.hpp       #声明所有物理层面的变量,队列,数组,函数 (后期重新改造)
        -PhysicsWorld.cpp       #实现所有物理层面的变量,队列,数组,函数 (后期重新改造)
    -render/                #渲染线程: 负责引擎的图形化渲染, 使用VulkanAPI,目前工作的重心
        -Renderer.hpp           #渲染轨入口: 消费变更事件, 请求mesh重建
        -Renderer.cpp           #实现: tick循环(收事件→请求重建), 首帧初始重建
        -VulkanContext.hpp      #Vulkan全链封装: 交换链/管线/深度与MSAA附件/缓冲/每帧绘制/重建
        -VulkanContext.cpp      #实现: 初始化链, drawFrame每帧循环, rebuildMeshFromBlocks重建
        -VulkanMesh.hpp         #方块mesh生成: 声明buildCubeVertices/buildCubeIndices
        -VulkanMesh.cpp         #实现: 生成立方体24顶点/36索引(6面×4顶点)
        -utils/                 #Vulkan样板工具集: 把初始化细节拆成可复用函数
            -Utils.hpp          #公共声明: createBuffer/mapAndCopy/createImage等
            -DeviceUtils.hpp    #物理设备选择/逻辑设备创建
            -DeviceUtils.cpp    #实现
            -SwapchainUtils.hpp #交换链创建(含格式/呈现模式选择)
            -SwapchainUtils.cpp #实现
            -ResourcesUtils.hpp #缓冲/图像资源: createBuffer/createImage/mapAndCopy
            -ResourcesUtils.cpp #实现(引擎里Vulkan资源操作都走这里)
            -ShaderUtils.hpp    #着色器加载与编译(SPIR-V)
            -ShaderUtils.cpp    #实现
            -CommandUtils.hpp   #命令池/命令缓冲创建
            -CommandUtils.cpp   #实现
    -shared/                #跨线程共享数据结构: 所有线程共用, 只含定义不含实现
        -Block.hpp              #方块体系: Block/BlockPos/BlockType/ChunkPos/ChunkData
        -PlayerInput.hpp        #玩家输入槽: 跨线程原子变量(点击序号/相机位置/视角)
        -Protocol.hpp           #线程间协议: 物理指令/物理回执/变更事件的定义
```

# 我的世界类型的沙盒游戏引擎 
>自带物理线程: 取代MC原版的固定方块, 物理化方块给予游戏更多玩法
>业务线程设计: 游戏引擎的最高权力, 所有东西都需要经过业务线程
>渲染线程: 依赖VULKAN_API, 只读线程, 游戏图形化显示
>输入线程: 负责获取玩家输入, 未来包括手柄API
