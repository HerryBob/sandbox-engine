# 发布与商业架构决策

> 本文档记录发布形态、售卖逻辑与启动器的定案（2026-11-09）。
> 经济目标 = 养活自己；模式 = 方案 A（本体收费 + 官方整合包免费分发）。
> **读者：模组作者 / 项目内部**。玩家侧不出现"引擎""整合包""DLL"等词——玩家只知道"这是一个游戏，开箱即玩"。
> 架构相关章节（第二、三节）是给模组作者看的；玩家向文档（商店页、教程、宣传）只讲玩法，不讲架构。

---

## 一、经济目标（定案）

> 目标：**养活自己**，月收入 1500–2000 元（税后）。
> 不追求爆款，不追求生态规模（见《玩法决策.md》项目目标段）。

### 1.1 目标换算

| 项 | 数值 | 说明 |
|---|---|---|
| 月到手 | 1500–2000 元 | 年 1.8–2.4 万 |
| 毛收入（Steam 30% 后） | 约 2.6–3.4 万/年 | 平台分成后 |
| 年销量（100 元定价） | 约 **260–400 份** | 含税按 400 份规划 |

### 1.2 销量参照（Steam 2026 数据）

| 口径 | 数值 |
|---|---|
| 全部 Steam 游戏销量中位 | 200–400 份 |
| 生存品类中位（≥50 条评论） | 8,000–20,000 份 |
| 工厂/自动化品类中位（≥50 条评论） | 15,000–30,000 份 |
| 同品类头部先例 | Scrap Mechanic 300 万份 |

**结论**：年会销 400 份 = 全部游戏的中位水平；1 万份 = 本品类中位水平（可争取的进阶目标）。

### 1.3 税负（量级估算，非税务建议）

| 层 | 内容 | 处理 |
|---|---|---|
| 美国预扣税 | Valve 为美国公司 | 填 **W-8BEN**（非美国纳税人声明）免除 |
| 中国增值税 | 数字产品销售 | 小规模纳税人现行优惠 **1%**（政策有时限，按当期确认） |
| 中国个税 | 收入性质 | **经营所得**（个体户，5%–35%，可核定征收）优于劳务报酬（20%–40%） |
| 外汇 | Steam 付美元 | 个人年度结汇 **5 万美元**额度；规模化后走个体户对公账户 |

**主体建议**：个体工商户（核定征收）——税负低、申报简单、有对公账户解决结汇。各地执行不同，需咨询当地税务/代账会计。

## 二、发布架构（方案 A · 定案）

> 详细内容已拆到《模组作者文档骨架.md》（作者向）。
> 要点：本体（引擎+核心系统）收费；官方整合包（全部玩法内容，以 DLL 形式实现）免费随本体分发；第三方整合包由社区决定。
> 玩家侧只需要一个结论：**开箱即玩**——安装 → 启动 → 直接进游戏，不出现"选整合包"步骤。

### 2.1 为什么选方案 A

| 方案 | 描述 | 判断 |
|---|---|---|
| **A（定案）** | 本体收费（含官方整合包），官方内容免费更新 | ✅ 玩家体验完整，收入有保障 |
| B | 引擎免费 + 官方整合包收费 | ❌ 玩家拿到"空引擎"，体验差 |
| C | 全免费 | ❌ 无收入来源 |

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 玩家认知负担（"引擎 + 模组"听不懂） | 对外只说"游戏"；架构是幕后 |
| 盗版（DLL 可复制） | 不投入过度防盗；价值在引擎 + 持续更新 |
| 引擎更新破坏第三方 mod | 版本标注 + 兼容层 + 启动器提示 |
| 启动器拖慢发布 | 尽早开发，最小版本先上（只做安装/更新） |
| 官方内容更新与引擎更新冲突 | 统一版本号 + 官方包随引擎发版 |

## 五、阶段规划

### 阶段 0：垂直切片（先验证"开箱即玩"）

- 本体 + 官方整合包（最小内容：1 个群系、1 套物理结构、1 套风、生存闭环）
- 启动器最小版：安装 + 启动 + 自动加载官方包
- **验收**：新机器安装 → 启动 → 进游戏 ≤ 3 步，无需手动装任何 mod

### 阶段 1：EA（抢先体验）

- 官方整合包内容扩展（生物/群系/自动化/遗迹教学）
- 启动器完整版（版本管理、依赖解析、一键更新、崩溃提示）
- 上 Steam 页面，积累愿望单（目标 7,000+ 触发推荐）

### 阶段 2：1.0

- 内容完整 + 第三方生态开放（mod 作者接入）
- 引擎性能优化持续（benchmark 验证）

## 六、验收标准

| 项 | 标准 |
|---|---|
| 开箱即玩 | 安装到进游戏 ≤ 3 步，无手动 mod 操作 |
| 官方整合包 | ≤ 3 个 DLL，加载时间可接受 |
| 启动器 | 能装、能更、能提示崩溃 |
| API 稳定 | 引擎更新不破坏官方内容；第三方有版本标注 |
| 经济目标 | 年销 400 份 ≈ 月入 1500–2000 元（税后） |
