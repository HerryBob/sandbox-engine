## 二、要解决的三件事（按收益排序）

1. **无 mip → 远处方块纹理闪烁**。缩小采样时相邻像素跳变，日常游玩可见，比"支不支持高清材质包"更实际。
2. **单图尺寸被锁死在 16**。任何非 16×16 的贴图直接拒收（落兜底格），模组无法自带高清贴图。
3. **固定格网装不进混合尺寸**。32×32 只有两条路——缩成 16（糊）或把格子放大到 32（16 的图也糊），都不成立。

## 三、阶段

### T1 · 坐标抽象（行为不变的铺垫）

| 改动 | 说明 |
|---|---|
| `AtlasSlot{row,col}` → `SpriteRect{x,y,w,h}` | 存放像素矩形；坐标类型从 uint8 放宽 |
| `slotUV()` 改像素归一化 | `{x/size, y/size, (x+w)/size, (y+h)/size}` |
| `fallbackUV()` 指向第 0 个 sprite 的矩形 | 语义不变，只是取法换了 |
| `build()` 改两段式 | 先 `stbi_info` 收全部尺寸 → 再布局 → 最后逐张写入（`架构决策-图集装箱.md` 待办第 2 项） |
| 布局仍走 16² 格网 | 这一步只为把"格"换成"矩形"，不动排布算法 |

**验收**：日志仍是 `48²（3×3 格）`、8 张全成功、占用 9/9；画面与改造前完全一致。调用点只有三处（`VulkanMesh.cpp` 两处 + `VulkanContext.cpp:749-753`），都必须只认 `glm::vec4`，不感知内部结构。

### T2 · 装箱 + mip（真正的改造）

| 步骤 | 内容 | 备注 |
|---|---|---|
| 1 | 收集阶段不再拒非 16²，记录每张的 `w/h` | 尺寸来自 `stbi_info`，不解码像素 |
| 2 | 实现装箱（排序 → 试装 → 分裂 → 扩边） | 算法与自检断言见 `架构决策-图集装箱.md` §装箱 |
| 3 | 每 sprite 四周加 1px padding，复制边缘像素 | 防 mip 采样跨格渗色 |
| 4 | CPU 侧逐级生成 mip（2×2 平均） | 透明像素要按 alpha 加权，不能直接平均 |
| 5 | `VkImage` 的 `mipLevels` = `floor(log2(size)) + 1`，逐级 `vkCmdBlitImage` | 现在是 `ResourcesUtils.cpp:51` 固定传 1 |
| 6 | sampler：mag 保持 `NEAREST`，min 改 `LINEAR`，`mipmapMode = LINEAR`，`maxLod` 按尺寸算 | 近处像素风不变，远处才走 mip |
| 7 | 准入规则：`w`、`h` 必须是 2^mip 的倍数（以 16 = 2⁴ 为准），否则拒 + 告警 | 不做缩放，与 2026-11-09 决策一致 |

**验收**：

- 装箱自检：造 16×16 / 32×32 / 24×24 三张合成图，断言矩形不重叠、像素落在正确偏移
- 混排：16² 与 32² 同图，方块贴图不错位；原木顶/侧、草方块顶/侧仍正确
- 反证：24×24 必须被拒（告警 + 落兜底格），且**不拉低**整张图集的 mip 级别
- 远处观察：方块纹理闪烁消失；sprite 边界无邻块颜色渗入（padding 有效）

### T3 · 多图集（有触发条件才做）

触发条件（满足任一）：

- 出现**动画方块纹理**（水 / 岩浆 / 火），需要频繁局部重传 GPU
- 粒子、GUI 精灵规模化，混在图集里导致过滤需求冲突
- 方块图集逼近 GPU `maxImageDimension2D`

拆分方案：`blocks` / `particles` / `gui` / `entity` 各自独立 stitch + mip + 更新。
**现在不做的理由**：图集才 48²，一张足够；实体纹理已经是独立 `VkImage`，等于半只脚在门外。

## 四、硬约束（不可协商）

1. **不缩放**：任何尺寸的贴图按原始像素放入，不改像素数量（缩放会被 mip 与像素风双杀）。
2. **mip 对齐纪律**：宽高必须是 2^mip 的倍数。MC 用 16（2⁴），任一张不满足会拉低整张图集的 mip。
3. **padding 必做**：1px 边缘复制。透明边距会让 mip 把"空"平均进来，出现暗边。
4. **上限取 GPU 上报**：`vkPhysicalDeviceProperties.limits.maxImageDimension2D`，不是硬编码 4096（`架构决策-图集装箱.md` 待办第 5 项）。
5. **坐标类型**：装箱坐标是 `uint16/uint32`，`AtlasSlot` 的 `uint8` 必须换掉，否则超过 256 边静默截断。

## 五、明确不做

| 不做的项 | 理由 |
|---|---|
| 逐 sprite 缩放 | MC 也不做；缩放会同时毁掉像素风与 mip 语义 |
| `atlases/*.json` 声明文件 | 2026-11-25 已改成自动收集，声明式反成维护负担；真要声明再回来 |
| `unstitch`（从大图切区域） | 当前没有图集拼图的资源形态 |
| 动画纹理（帧 + `.mcmeta`） | 归 T3 触发后再说 |
| 多格 span（占 2×2 格） | 2026-11-09 已否决（24×24、40×40 进不来） |
| 全局升 `kAtlasTile` | 同上已否决（分辨率变全局约束） |
