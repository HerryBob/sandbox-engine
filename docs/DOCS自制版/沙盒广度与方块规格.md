# 沙盒广度与方块规格

> 定位：沙盒广度的落地清单——方块种类与材质维度，是物理化的"画布规格"。
> 原则：**广度是核心（9–10 分），装饰深度不做**。
> 状态：初版清单（2026-11-10），具体数值与实现细节待调参。

---

## 一、沙盒广度的三个维度

| 维度 | 内容 | 标准 |
|---|---|---|
| **方块种类** | 6 类功能方块 + 建造材料 + 装饰方块 | 玩家能造出各种结构 |
| **建造自由度** | 方块可组合、可连接、可整体移动 | 不受离散方块限制 |
| **世界可交互** | 可挖、可改、可破坏、可承重 | 物理化有交互对象 |

> 物理化与沙盒强绑定：方块种类与建造自由度是物理化的载体——沙盒广度不够，物理化就没有表现空间。

---

## 二、6 类功能方块（最小集合）

> 全功能方块化的落地：只提供原子方块，玩家组合出一切子系统。以下为**初版建议清单**，实现时按需增减。

### 1. 基础类（结构骨架）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 结构方块 | 承重、连接、构成结构主体 | 质量/强度随材质 |
| 连接件 | 方块间刚性连接、装配体定义 | 决定结构整体性 |
| 地基/锚点 | 固定结构、防止漂移 | 高摩擦/固定 |

### 2. 运动类（让结构动起来）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 旋转关节 | 绕轴旋转（轮子、转子、炮塔） | 扭矩/转速上限 |
| 直线执行器 | 伸缩（活塞、升降） | 行程/推力 |
| 铰链 | 折叠/摆动（舱门、机械臂） | 角度限制 |
| 弹簧/阻尼 | 悬挂、缓冲 | 刚度/阻尼 |

### 3. 动力类（能量的产生与传递）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 旋转动力源 | 产生旋转（电机/风车/蒸汽机） | RPM / 应力（SU） |
| 传动件 | 传递旋转（轴/齿轮/皮带） | 传动比/损耗 |
| 储能件 | 储存能量（飞轮/电池） | 容量/充放速率 |

### 4. 逻辑类（控制与信号）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 开关 | 手动控制 | 二态 |
| 传感器 | 感知（压力/光照/距离/速度） | 阈值可调 |
| 逻辑门 | 与/或/非/比较 | 布尔运算 |
| 定时器 | 延时/周期 | 时间参数 |
| 线信号接口 | 有线连接（RedstonePen 式画线） | 不耗能 |

### 5. 传输类（物品与流体的移动）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 传送带 | 连续传送物品 | 速度/方向 |
| 管道 | 传输流体/气体 | 流量/压力 |
| 滑槽/漏斗 | 重力输送、分拣 | 容量 |
| 抓取器 | 搬运方块/物品 | 抓取范围 |

### 6. 交互类（玩家与世界的接口）

| 方块 | 作用 | 物理属性 |
|---|---|---|
| 操作方块 | 按钮/拉杆/控制台 | 玩家可交互 |
| 容器 | 存储物品/流体 | 容量 |
| 工作台 | 合成/加工 | 配方集 |

## 三、材质维度（物理化的画布）

> 材质不是装饰，是**物理参数**：同一形状不同材质，物理表现完全不同。这是沙盒广度的一部分。

| 材质 | 质量 | 摩擦 | 强度 | 典型用途 |
|---|---|---|---|---|
| 木 | 轻 | 中 | 低 | 轻型结构、飞行器骨架 |
| 石 | 重 | 高 | 中 | 地基、承重 |
| 金属 | 中 | 低 | 高 | 机械部件、承重结构 |
| 轻金属/复合 | 轻 | 低 | 高 | 高性能结构（后期解锁） |

> 参数为定性描述，具体数值待物理调参。

**材质的意义**：
- 结构能不能飞，取决于"总质量 vs 推力/升力"
- 结构会不会断，取决于"材质强度 vs 受力"
- 结构稳不稳，取决于"摩擦 vs 外力"
- **同一套方块，换材质就是另一套玩法**——这是广度带来的深度

## 四、装饰类的边界

| 提供 | 不做 |
|---|---|
| 颜色/纹理丰富的装饰方块（石砖、木纹、彩色方块、灯具） | 家具分类系统 |
| 装饰方块的材质变体 | 装饰评分/收集 |
| | 装饰套装/DLC |
| | 装饰玩法 |

**判断**：装饰方块是"材质选项"，不是"系统"。提供方块，不做系统。

---

## 五、判断标准

每个新方块过三问：

1. **它能让玩家造出新的物理结构吗？** → 是：核心，全力做
2. **它只是让墙更好看吗？** → 是：提供方块，不做系统
3. **它是某个"系统"的入口吗？** → 是：警惕系统膨胀，回到"6 类原子方块"框架

## 六、与其它定案的关系

| 定案 | 与本清单的关系 |
|---|---|
| 物理化 | 结构物理依赖材质参数（质量/摩擦/强度） |
| 风 | 风影响结构 = 受风面积 + 质量 + 材质 |
| 自动化 | 动力/传输/逻辑方块是其原子组件 |
| 活建筑 | 运动类 + 动力类方块让建筑"活"起来 |
| 遗迹教学 | 用这些方块搭出"运转中的教学结构" |
| 全功能方块化 | 本清单就是那 6 类的具体化 |
