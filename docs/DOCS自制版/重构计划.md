**重构计划**
# 规则0: 先建冒烟基线
	- tools/smoke.ps1：构建 → 运行 15s → 抓 7 项自检 + tps + 方块数 + chunk 数 + 预热列数
	→ 无参：写入 bench/baseline.txt
	→ -Compare：逐项比对，输出 PASS/FAIL
# 规则1: 不新增行为/功能，只拆已有多功能函数（允许新增函数与文件）可以加文件夹或文件 但要注释说明来自哪里 同时保证同类型或相似文件在一个文件夹里
	-检查方式: 7 项自检全过 + tps 与拆分前一致（±0.1）+ 世界方块数/chunk 数完全一致。
	① 拆分（函数拆成单一职责）      
	② 移动文件 / 分文件夹                    
# 规则2: 对所有函数和文件进行重命名
	例外（与规则5 一致）：render/** 本轮不改名
	-命名规则:
	R1  队列    <发送线程>To<接收线程><内容>_        businessToPhysicsCommands_
	R2  锁      <被保护数据>Lock_                   chunksLock_
	R3  常量    k + PascalCase                      kMaxApplyPerTick
	R4  计数    <内容>Count_                        appliedColumnCount_
	R5  布尔    函数 is/has/can/try                  isAllAir()
              成员 过去分词 + _                    started_
	R6  动词词表
        生命周期: init  start  stop
        推进:     tick
        解析:     load  parse  build
        资源:     create  destroy  upload
		消息:     push  pop  flush  sync       
        保留词（存量准确，不强制改）: decode resolve validate attach detach release
	R7  回调    onXxx（跨边界）/ handleXxx（内部）
	R8  成员变量 类成员加尾下划线 _
              例外：struct（数据聚合）字段不加
                    ModBlockDef::name / RigidBody::motion / CameraState::camX
	R9  全局变量 g_ 前缀                            g_host / g_api
	R10 集合变量 = 名词复数，直接拼
		后缀只在"用法有实质差异"时加：
			Set   去重集合（判重/求交）        requestedColumnSet_
			Map   键值查找                     chunkMap_
			（队列由 R1 覆盖，不再加 Queue 后缀）
			禁止实现后缀：List / Array / Vector / Collection
			允许介词连词：columnsToUnload_ / blocksInArea_
	附1 枚举值 = PascalCase                         MotionType::Dynamic
	附2 不可改名域 = modapi/**（本轮不动，见附3）、shared/state/**、shared/protocol/**
	附3 待办（与"C 接口改造"同一轮做）:
		modAPI 字段语义改进
          hardness     → miningHardness
          opaque       → 补注释或改名（说明是"参与面剔除"还是"视觉不透明"）
          loadedChunks → nonEmptyChunkCount
	附4 缩写白名单（保留）：Pos  Id  AABB  UV  GL  API  dt
     新增代码不再发明新缩写（如 Ctx → Context、Mgr → Manager）
	附5 构建测试时不每个函数测试 采取批次测试 每重命名一批 进行一次测试

# 规则3: 不修bug, 不修任何在重构过程中的bug, 除非导致引擎报错无法启动,只记录
	-记录在"docs\bug记录.md"
# 规则4: 跨线程交互依靠无锁环形队列 未跨线程的也可但要说明
	-同线程如果是为了保证性能 可以使用队列 但要说明清楚
# 规则5: 业务线程 物理线程 输入线程 尽量只在本地使用自己的函数 如果需要别的线程的数据 使用环形无锁队列传递数据或使用原子变量转递状态 并尝试将数据层和逻辑层分开 类似于业务线程的world
	-线程类不持有别的线程的数据对象 —— 成员里只允许出现：自己的队列 / 原子槽 / 自己拥有的小对象；不拆数据对象的内部。
	-"渲染线程豁免（只读直取，本轮不改）"
# 规则6: 在重构过程中遇到了性能问题暂时不管 只记录
	-"docs\性能问题记录.md"
# 规则7: 模组接口相关内容暂时不动 完成C接口改造即可
# 规则8: 每次重构都需要重新构建并运行引擎并测试
	-构建 → 运行 15s → 对：7 项自检 + tps + 方块数 + chunk 数 + 预热列数
	→ 与上一次逐项比对，不一致就停
